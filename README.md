# 📊 Power BI Retail & Sales Analytics Project

## 🚀 Overview

This project was completed during my **Data Technician Bootcamp** and demonstrates the use of **Microsoft Power BI** to transform, clean, analyse, and visualise business data.

The project focused on building interactive reports and dashboards using retail and sales datasets, enabling users to explore trends, monitor performance, and make data-driven decisions through engaging visualisations and storytelling.

---

## 🛠️ Skills Demonstrated

### 🔄 Data Transformation & Cleaning (Power Query)
- Imported data from multiple sources
- Cleaned and transformed datasets using Power Query
- Changed data types and formats
- Removed errors and inconsistencies
- Prepared data for reporting and analysis
- Improved data quality and usability 

### 📊 Data Modelling & DAX
- Created calculated columns using DAX
- Built custom measures for business reporting
- Applied data modelling principles
- Performed aggregations and calculations
- Developed reusable metrics and KPIs
- Configured semantic models to improve analysis capabilities

### 🎛️ Interactive Reporting
- Built interactive Power BI reports
- Used slicers to filter data dynamically
- Applied report-level and visual-level filters
- Enabled user-driven data exploration
- Designed intuitive report layouts for improved usability

### 📈 Data Visualisation
Created a variety of visualisations to support analysis and reporting:

- 📊 Bar Charts
- 📉 Line Charts
- 🥧 Pie Charts
- 🗺️ Maps
- 📋 KPI Cards
- 📈 Trend Analysis Visuals

These visualisations were used to identify patterns, compare performance, and communicate insights effectively.

## 📖 Data Storytelling

A key objective of this project was to transform raw retail and sales data into meaningful business stories.

The dashboards were designed to:

- 📌 Highlight sales performance trends
- 📌 Identify high-performing products and regions
- 📌 Monitor key business KPIs
- 📌 Support data-driven decision-making
- 📌 Present complex information in a clear and accessible format

By combining interactive reports with impactful visualisations, users can explore the data and uncover insights that support business growth and operational improvements.
